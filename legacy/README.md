# 舊版 NV 工具

`NV_tool_3G.py` 為整合前的獨立版本，保留原始內容作版本比較。主要入口為 [NV Band Preference Center v3](../tools/nv/nv_band_preference_tool.py)。

| 項目 | 舊版 `NV_tool_3G.py` | 主版 `nv_band_preference_tool.py` |
| --- | --- | --- |
| 程式內設定的 NV 項目 | 6828、1877、4548 | 前述三項，加上 65633、74087、74213 |
| 介面 | 單一 3G／4G 工具 | 頂層分頁整合 4G／5G 與 3G／4G |
| 每個項目的欄位 | 單一 Uint64 | LTE／舊項目為單一 Uint64；NR 詳細頁為 5 個 Uint64 |
| 頻段／數值互轉、明細、CSV | 有 | 有 |
| 本次整理的錯誤修正與測試 | 保留原貌，未套用 | 套用於主版 |

保留舊版是為了看出整合前後的程式結構，並非另一個建議使用的版本。舊版仍有 CSV 輸入欄與結果欄可能未同步的問題；請以主版執行示範。

舊版開頭註解的十六進位範例有一處筆誤：`1, 8, 20` 正確結果是 `524417 = 0x0000000000080081`。此處標明勘誤，原檔保持原貌。

兩個版本皆依程式中的一般位元位置規則計算，不代表 NV 編號與所有實際平台相容。詳細限制見 [NV 說明](../docs/nv-tool.md)。
