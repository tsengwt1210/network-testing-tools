日期：2026-10-14。環境：Windows、Python 3.12.6、Tk 8.6。

```powershell
python -B -m unittest discover -s tests -v
```

結果：**25 項測試全部通過**，其中 NV 14 項、iPerf 11 項。測試不建立 Tk 視窗，不啟動 iPerf3，也不連接設備或測試網路。

| 範圍 | 驗證內容 |
| --- | --- |
| NV 邊界 | 1、64、65、128、277、320 的已知欄位結果；321、512 等越界拒絕 |
| NV 往返 | 320 個單一 bit，以及固定種子產生的 100 組組合 |
| 輸入解析 | 清單、區間、十進位、十六進位、空值、重複、負數與 Uint64 上限 |
| NV CSV | 兩組頁面的不一致輸入攔截，以及一致資料的實際 CSV 內容 |
| iPerf 指令 | Server、Client、TCP、UDP、反向與進階參數組合，必填項與數字檢查 |
| iPerf log | 表頭先於工作建立、相同時間戳不覆蓋、輸出追加與退出碼傳遞 |
| iPerf 程序 | 以 mock 模擬啟動失敗、非零退出及手動停止；不執行外部程式 |
| 執行檔尋找 | 同資料夾優先、PATH 備援及找不到執行檔的錯誤 |
